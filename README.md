# kaigaigumi-redirect

`kaigaigumi-watch.com`(www なし)に来た人を、ブログ本体の `https://www.kaigaigumi-watch.com/` へ移動させるためのページです。GitHub Pages で公開しています。

- `index.html`:トップページに来た人を移動させる
- `404.html`:ほかの住所(記事のURLなど)で来た人も、同じページの www 付きの住所へ移動させる
- `CNAME`:このページを `kaigaigumi-watch.com` で表示する設定
- `ads.txt`:Googleアドセンスの販売者情報(アドセンスは www なしの住所でこのファイルを確認する)
